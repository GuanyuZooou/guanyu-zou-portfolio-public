Inspect a figure and check colour contrast in your browser. Export palette choices as JSON or CSS and save a report from Transfer Lab.

Inspect colours in a figure

Inspect samples colours from an image in your browser. It shows how common each colour is, suggests roles such as a data series, a neutral or a highlight, and checks contrast against white. Check those suggestions against what the figure is meant to communicate.

  • Inspect and Transfer browser code

Try the palette on a new figure

Transfer uses the new figure’s chart type, number of series and planned emphasis to suggest which colours to use. It flags cases where the recommendation is uncertain. The built-in example warns when it cannot find a clear neutral. Check that the result is readable and the emphasis still makes sense before using the export.
