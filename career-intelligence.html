Source snapshot 2026-11-26

A public synthetic demo and a local workflow for mapping requirements, reviewing translations and drafting applications.

Start with proof for each requirement

The core maps requirements to Direct, Transferable, Latent, Gap or Missing evidence. Stable source identifiers carry through English and Simplified Chinese, and pending or edited translations are held back from draft wording while source coverage remains visible.

  • Evidence-mapping and draft logic
  • Workspace contract

Keep the private workbench local

The single-user workbench and CLI share a versioned JSON workspace with revision checks and atomic saves. The public browser demo uses a synthetic fixture. A candidate reviews mappings, source strength and translation before using a draft.

  • Workspace persistence code

What was tested

The repository includes 14 synthetic workflow tests, all passed in this review, plus a manual Chromium walkthrough covering persistence, translation and draft validation. This prototype has no hiring-outcome study or multi-user deployment.
