02 / DATA PROCESSING

Turn simulation outputs into tables

My Python scripts turn simulation files into tables and keep each run’s settings separate. Checkpoints let me resume interrupted runs.

Use fitted models in simulations

04 / SCIENTIFIC WRITING TOOLS

Find writing rules and put them to work

I built two AI skills for scientific writing. One derives writing principles from published papers. The other helps researchers organise evidence and revise manuscripts.

AnalyseSource examplesDistilRules and exceptionsReviewDrafts and claims

The first skill records examples and exceptions for each proposed rule. The editor checks whether claims, figures and section order work together.

The editor can flag where a claim needs support. The researcher checks the science and decides which edits to accept.
