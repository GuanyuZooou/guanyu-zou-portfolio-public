Find patterns across papers

The skill helps an analyst compare how authors explain methods, present results and qualify claims. It records what the papers show, what an author says about their choices and what the analyst infers. When examples disagree or the author’s contribution is unclear, the notes record that uncertainty.

Turn the notes into a writing guide

The skill writes a guide and a table linking each rule to examples and exceptions. A reviewer decides which rules are well supported and where they apply. The companion Editor can use a reviewed guide when working on another manuscript.

Check the files before using the guide

In a check of the public scripts, the setup script created the expected files and refused to overwrite a populated directory. The checker caught incomplete records. The reviewer still decides whether the examples support the proposed rules.
