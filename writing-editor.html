Source snapshot 2026-08-13

A reusable instruction set and rule catalogue for reviewing how a scientific argument is built.

Apply an editorial method to a new manuscript

The skill directs an agent to inspect the source evidence and manuscript context before proposing an organising claim, figure order or revision. The rule catalogue and reference method make the reasoning available for human review.

  • Public skill specification
  • Editorial reference method
  • Rule catalogue

Keep editorial decisions accountable

For example, rules R08 and R12 ask the reviewer to separate observations from proposed mechanisms and preserve uncertainty unless further evidence supports a stronger statement. The agent surfaces issues and proposes revisions. The author owns the scientific inference and approves changes in meaning. The public evidence is the skill and rule artefacts. Comparative effects on manuscript quality have not been established.
